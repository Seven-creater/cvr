## Visual references

The redesign follows the media-first figure grammar used by recent
audio-visual retrieval papers: real frame strips establish the task, compact
symbols encode modality operations, and quantitative evidence is separated
from the method schematic. The visual audit referenced the published figures
in CoVA (`https://arxiv.org/pdf/2601.22508`), AVIGATE
(`https://arxiv.org/pdf/2504.02397`), OmniCVR
(`https://openreview.net/pdf?id=KxxR7emO5K`), and OmniRet
(`https://arxiv.org/pdf/2603.02098`). The resulting artwork is original and
does not reproduce their figure assets.

The generic `nature-figure` static validator passes syntax, font family, font
size, color-map, sampling, exclusion, demo-data, log, and backend checks. It
flags Matplotlib-specific `svg.fonttype`, `pdf.fonttype`, and in-script
`savefig` requirements because this Python source emits native Draw.io XML and
the separate Node exporter creates SVG/PDF/PNG. Direct inspection above
verifies editable SVG text, vector PDF delivery, PNG output, and 600-dpi TIFF.
