  query-specific pre-edit negative that dominates top-rank errors; exact
  own-reference masking exposes this failure across E5 and ImageBind.
- Figure 2 claim: source-aware pairing, modality-isolated gates, stability

- Figure 1 uses a real fixed Test1000 example with paired filmstrips and
  waveforms; the gallery no longer overlaps its label.
- Figure 2 orders the information gates as audio-only, muted-video, then full
  audiovisual review.
- The repeat check is labeled `STABILITY AUDIT`, not human consensus.
- The dashed freeze path runs from TEST to FULL1000.
- Colors use both hue and direct labels, so red/green is not the sole carrier
  of meaning.

The generic Python figure validator reports missing Matplotlib-specific
`svg.fonttype`/`pdf.fonttype` settings and in-script `savefig` calls because the
Python source builds native Draw.io XML and a separate exporter creates the
delivery files. Those findings are not applicable to this split Draw.io
pipeline; the direct SVG inspection above verifies editable text and both
vector formats.

## Reproduction order

```text
python paper/figures/build_drawio_figures.py
node paper/figures/export_drawio_figures.cjs
python paper/build_paper_assets.py --strict --skip-figures
cd paper
latexmk -norc -pdf -outdir=build_main main.tex
```

The Draw.io exporter requires a local Chrome/Chromium executable, Playwright,
Python, and Pillow. Its extended initial-load timeout accommodates the current
official web editor payload on slow connections.
