# Code and Data Supplement Upload

Upload `Audio-CVR_code_and_data_anonymous.zip` to the OpenReview **Code and
Data Supplement** field. The archive is anonymous and excludes personal paths,
raw licensed videos, third-party backbone weights, caches, and credentials. It
does include the complete derived annotation records, frozen-data commitments,
five lightweight adapter checkpoints, final per-query evidence, source code,
and tests.

This upload is optional in the OpenReview form but recommended because AAAI-27
reviewers evaluate reproducibility based on materials available at submission
time.

Do not replace this upload with an external repository link. Use the internal
GitHub branch only to synchronize and test the exact archive before submission.
